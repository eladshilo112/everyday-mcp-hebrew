# 006, בודק התנגשויות יומן מקומי

שרת MCP מקומי שקורא קובצי יומן בפורמט ICS, מציג אירועים ומזהה שיבוצים חופפים מראש. הכלי מיועד לכמה יומנים מקומיים, למשל עבודה, לימודים ומשפחה, ופועל בלי חשבון, בלי רשת ובלי שינוי של קובץ המקור.

## שורה תחתונה

מגדירים תיקיית עבודה, מוסרים נתיבים לקובצי `.ics` שבתוכה וחלון זמן מפורש של עד 90 יום. השרת מחזיר אירועים או התנגשויות בסדר קבוע, יחד עם אזהרות ברורות על רשומות שלא ניתן לפרש.

## שלושת הכלים

### `find_conflicts`

קורא קובץ אחד או יותר, מרחיב אירועים חוזרים ומחזיר חפיפות בין אירועים באותו קובץ וגם בין קבצים שונים. שתי פגישות שנוגעות בדיוק בגבול, כלומר סיום אחת שווה להתחלת השנייה, אינן נחשבות להתנגשות.

שדות הפלט המרכזיים:

* `events_scanned`, מספר מופעי האירועים שנבדקו.
* `conflict_count`, מספר ההתנגשויות המלא.
* `conflicts_returned`, מספר ההתנגשויות שהוחזרו בפועל.
* `conflicts_omitted`, מספר ההתנגשויות שלא הוחזרו בגלל התקרה.
* `conflicts`, עד 500 התנגשויות, בסדר קבוע לפי זמן תחילת החפיפה ואז שם קובץ המקור.
* `warnings`, אזהרות מובנות על אירועים פגומים או לא נתמכים.

### `list_events`

מחזיר את מופעי האירועים המנורמלים בחלון הזמן. הרשימה מוגבלת ל־500 פריטים ומלווה בשדות `event_count`, ‏`events_returned` ו־`events_omitted`.

### `check_overlap`

בודק שני טווחי זמן ישירים, בלי לקרוא קובץ. כל ארבעת הזמנים חייבים להיות בפורמט ISO 8601 עם `Z` או היסט מספרי מפורש, למשל `2026-09-10T09:00:00+03:00`.

## קלט לקובצי יומן

`find_conflicts` ו־`list_events` מקבלים אותו חוזה:

```json
{
  "working_directory": "C:\\Users\\me\\Calendars",
  "files": ["work.ics", "personal.ics"],
  "window_start": "2026-09-01T00:00:00Z",
  "window_end": "2026-09-30T00:00:00Z"
}
```

כללים:

* `working_directory` הוא גבול הרשאה מקומי מחייב.
* כל קובץ חייב להימצא בתוך התיקייה גם אחרי פתרון הנתיב בפועל.
* נתיבי URL, נתיבי UNC, קישורים סמליים, קבצים שאינם רגילים וקבצים שאינם מסתיימים ב־`.ics` נדחים.
* מתקבלים עד 50 קבצים, כל אחד עד 5,000,000 בתים.
* חלון הזמן חייב להיות חיובי, מפורש וקצר או שווה ל־90 יום.
* עד 2,000 מופעי אירועים מורחבים מנותחים בכל קריאה. אם התקרה מושגת, מוחזרת אזהרה מפורשת.

## כללי ICS נתמכים

הפרסר נמצא כולו בקוד המקור של הפתרון ותומך בשורות ICS מקופלות ובבלוקי `VEVENT`. השדות הנקראים הם:

* `DTSTART`
* `DTEND`
* `SUMMARY`
* `UID`
* `RRULE`

אירוע בלי `DTSTART` או `DTEND`, טווח לא תקין או תאריך פגום, נדחה כאירוע בודד ומייצר אזהרה בלי להפיל את השרת. `UID` חסר מוחלף במזהה מקומי יציב ומייצר אזהרה. אירועי יום שלם עם `VALUE=DATE` נתמכים, כאשר `DTEND` נחשב לגבול סיום בלעדי לפי ICS.

## אירועים חוזרים

נתמכות חזרות `DAILY` ו־`WEEKLY` עם `INTERVAL`, ‏`COUNT` ו־`UNTIL`. ההרחבה נעשית רק בחלון שהמשתמש מסר, עד 90 יום. תדירות אחרת או כלל פגום משאירים את מופע הבסיס בלבד ומחזירים אזהרה. אין הרחבה בלתי מוגבלת ואין הורדת נתוני יומן או אזורי זמן מהרשת.

## אזורי זמן

זמן שמסתיים ב־`Z` מושווה כ־UTC. זמן צף ללא `TZID` מפורש כ־UTC ומייצר אזהרה. אזורי הזמן הבאים מנורמלים באמצעות כללים קבועים שנמצאים בקוד:

* `UTC`, ‏`GMT`, ‏`Etc/UTC`, ‏`Etc/GMT`
* `Asia/Jerusalem`
* `Asia/Kolkata`, ‏`Asia/Calcutta`
* `Asia/Tokyo`
* `Europe/London`
* `Europe/Berlin`, ‏`Europe/Paris`
* `America/New_York`
* `America/Los_Angeles`

כללי שעון הקיץ של האזורים הנתמכים מחושבים מקומית לפי התאריך. `TZID` שאינו ברשימה אינו מנוחש, האירוע נדחה עם `unsupported_timezone`. המימוש אינו מפרש רכיבי `VTIMEZONE` מותאמים אישית ואינו מתאים ללוחות היסטוריים לפני 1970.

## פלט MCP

כל כלי מחזיר גם טקסט קריא בשדה `content` וגם אובייקט מלא בשדה `structuredContent`. כשקיימת שגיאת קלט או נתיב, מוחזרים `ok: false`, ‏`isError: true` וקוד שגיאה מובנה. אזהרה על אירוע יחיד אינה מכשילה קובץ תקין.

## פרטיות ובטיחות

* קריאה בלבד. השרת אינו כותב, מעביר, משנה שם או מוחק קובצי יומן.
* אין לקוח רשת, טלמטריה, חשבון, התחברות או מפתח API.
* אין הרצת פקודות ואין שימוש בשירות חיצוני או במודל שפה.
* הנתונים נשארים בזיכרון התהליך הדרוש לקריאה ואינם מועלים או נשמרים במקום אחר.
* התוצאות דטרמיניסטיות עבור אותם קבצים ואותו קלט.

## התקנה, בדיקה ובנייה

נדרשת סביבת Node.js בגרסה 20 ומעלה.

```bash
npm install --ignore-scripts
npm run check
npm run build
npm test
```

כל גרסאות התלויות מקובעות במדויק ב־`package.json`. אין סקריפטים שפועלים בזמן ההתקנה.

## הפעלה

```bash
npm start
```

לאחר הבנייה, לקוח MCP יכול להפעיל את `dist/src/server.js` באמצעות `node` כשרת stdio.

## English quick start

Build with `npm run build`, start with `npm start`, and call `find_conflicts` or `list_events` with an explicit local `working_directory`, one or more `.ics` paths inside it, and an ISO 8601 window of at most 90 days. `check_overlap` compares two direct ISO intervals. Results include readable text and `structuredContent`, use half-open interval semantics, cap detailed arrays at 500 items, and remain deterministic, read-only, local-first, telemetry-free, and network-free.
