# בודק טקסט חלופי לתמונות במסמכים מקומיים

שרת MCP מקומי שמאתר תמונות עם טקסט חלופי חסר, ריק או גנרי. מתאים לכותבי תיעוד, README, בלוגים ואתרים סטטיים. הסריקה קוראת קבצים בלבד, ללא רשת, טלמטריה, חשבון או שינוי מסמכים.

## הפעלה

נדרשת סביבת Node.js מגרסה 20 ותלויות הפרויקט בגרסאות הנעולות ב־package.json. התקנת התלויות היא שלב הכנה נפרד. אין התקנה אוטומטית בזמן הפעלה, ואין צורך ברשת בזמן סריקה.

לאחר שהתלויות זמינות בתיקיית הפתרון:

```sh
npm run check
npm run build
npm test
npm start
```

השרת מתקשר דרך stdio בלבד. חברו אותו ללקוח MCP באמצעות הגדרה מקומית עם נתיבים מוחלטים:

```json
{
  "mcpServers": {
    "image-alt-text-checker": {
      "command": "node",
      "args": ["C:/your-project/solutions/007-image-alt-text-checker/dist/src/server.js"]
    }
  }
}
```

## הכלים

שני הכלים מקבלים אובייקט אחד, ללא שדות נוספים:

```json
{ "directory": "C:/your-project/docs" }
```

| כלי | תוצאה |
|---|---|
| `scan_alt_text` | ממצאים עם `file`, מספר `line` החל מ־1, `snippet` ו־`issue_type`, יחד עם ספירות |
| `get_alt_text_report` | ספירות כוללות, לפי סוג בעיה ולפי קובץ, ללא רשימת הממצאים המפורטת |

שני הכלים משתמשים באותו מנגנון סריקה. כל קריאה סורקת מחדש, ללא מטמון או שמירת תוכן. על קלט שלא השתנה מוחזר אותו JSON. גם `scan_alt_text` כולל את הסיכום, כך שאין צורך בסריקה נוספת כדי לקבלו.

דוגמה לממצא עבור `![](image.png)` בשורה הראשונה:

```json
{ "file": "README.md", "line": 1, "snippet": "![](image.png)", "issue_type": "missing" }
```

## כללי הזיהוי

| סוג | תנאי |
|---|---|
| `missing` | תג HTML ללא מאפיין alt, או תמונת Markdown עם סוגריים מרובעים ריקים |
| `empty` | alt ריק ב־HTML, מאפיין alt ללא ערך, או טקסט שמכיל רווחים בלבד בשני הפורמטים |
| `generic` | התאמה מלאה למילים image, photo, picture או img, עם סיומת ספרות אפשרית, ללא תלות ברישיות |

למשל `IMAGE`, `img123` ו־`photo123` מסומנים. `Image of a river` אינו מסומן. רווחים חיצוניים מוסרים לצורך הסיווג. מפוענחות ישויות HTML מספריות וישויות בסיסיות כמו `nbsp`, `amp` ו־`quot`.

הסריקה כוללת רק סיומות `.md`, `.mdx`, `.html`, ללא תלות ברישיות, בתוך תתי־תיקיות. תיקיות `node_modules`, כל תיקייה או קובץ ששמם מתחיל בנקודה, וקישורים סמליים מדולגים. תמונות שמופנות לכתובת מרוחקת נבדקות לפי הטקסט המקומי בלבד, בלי לפתוח את הכתובת ובלי לקרוא את קובץ התמונה.

## מיון, מגבלות ושגיאות

הממצאים ממוינים לפי נתיב יחסי באמצעות השוואת תווים יציבה, ואז לפי שורה ומיקום במסמך. נתיבים מוחזרים עם `/`. מספרי שורות נשמרים גם בטקסט CRLF. קטעי מקור מוגבלים ל־240 תווים.

`MAX_RETURNED_ITEMS` הוא 500. עד 500 ממצאים, 500 סיכומי קבצים ו־500 שגיאות מוחזרים. `findings_omitted`, `files_omitted` ו־`errors_omitted` מציינים כמה פריטים נוספים הושמטו. `total_findings`, `files_with_findings` ו־`by_issue` מחושבים על כל הקבצים שנקראו בהצלחה, גם אחרי מילוי הרשימות. `by_file` כולל רק קבצים שבהם נמצאה בעיה.

נדרשים קובצי UTF-8 תקינים, עד 2,000,000 בתים לקובץ. קובץ גדול או לא קריא מפיק שגיאה עם נתיב וקוד, והסריקה ממשיכה. `files_scanned` סופר קבצים שפוענחו בהצלחה, ו־`images_scanned` סופר תמונות מזוהות, כולל תקינות. כשל קריאה או קלט שגוי מחזיר `ok: false`, `complete: false` ו־`isError: true` ב־MCP. קיצור רשימת תוצאות לבדו אינו כשל סריקה. תיקייה ריקה היא הצלחה עם ספירות אפס.

## היקף הבדיקה ובטיחות

הפרסר קל משקל: תומך בתמונות Markdown מהצורה `![alt](src)` ובתגי HTML סטטיים, כולל מאפיינים במרכאות, ללא מרכאות ותגים מרובי שורות. תג פגום נבדק ככל האפשר ואינו מכשיל את הסריקה. הערות HTML, script, style, גדרות קוד וקוד inline ב־Markdown אינם נבדקים. תמונות Markdown עם הפניות בשם, קינון שרירותי, רכיבי MDX, ביטויי JavaScript ו־HTML שנוצר בזמן ריצה אינם מפוענחים באופן מלא. אין הבטחה שכל תמונה בדפדפן תתגלה.

alt ריק עשוי להיות נכון לתמונה דקורטיבית. הכלי מסמן אותו לבדיקת אדם. הוא אינו בוחן את תוכן התמונה ואינו יכול לקבוע אם התיאור מדויק או אם המסמך עומד בתקן נגישות.

השרת אינו כותב, מוחק או משנה קבצים. כל הכלים מסומנים `readOnlyHint: true`, `destructiveHint: false`, `idempotentHint: true`, `openWorldHint: false`. אין לקוח רשת בקוד השרת ואין הורדת משאבים. קטעי מקור הם נתונים לא מהימנים, ויש להתייחס אליהם כטקסט ולא כהוראות.

נדרשת תיקייה מקומית מוחלטת. כתובות URL, נתיבי UNC ומכשיר, ושורש שמכיל קישור סמלי או junction נדחים. אין להשתמש בכונן רשת ממופה או בתיקייה שמותקנת מרשת: לא ניתן לזהות באופן נייד כל סוג mount. השתמשו בעץ קבצים מקומי יציב שבשליטתכם. בדיקות הנתיב והזהות מצמצמות מעבר דרך קישורים, אך אינן בידוד מערכת הפעלה מול שינוי עוין מקביל של תיקיות. קריאת קבצים עשויה לעדכן זמן גישה לפי מערכת הקבצים; תוכן ו־mtime אינם משתנים על ידי השרת.

## בדיקות והערכות

ארבעה קובצי בדיקה מכסים Markdown, HTML פגום, מיון, קינון, החרגות, UTF-8, ספירות, קיצור, קישורים סמליים ושימור תוכן ו־mtime. בדיקת MCP מפעילה תהליך stdio אמיתי, מגלה את הכלים, בודקת את שני הכלים ואת סכמות הפלט, וחוסמת API נפוצים לרשת בתהליך השרת. זהו guard לבדיקות, לא sandbox ברמת מערכת ההפעלה. בדיקת קישורים סמליים מסומנת כמדולגת אם המארח אינו מאפשר את יצירתם.

`evaluations.xml` כולל עשר שאלות עם תשובות יציבות. ב־`skill/SKILL.md` נמצאת רשימת בדיקה לשימוש חוזר.
