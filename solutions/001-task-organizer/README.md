# 001, מארגן משימות וסדר יום

יש רשימת משימות בראש, בוואטסאפ או בפתק, אבל אין מושג מאיפה להתחיל?

הכלי הזה מקבל טקסט חופשי בעברית או באנגלית ומחזיר סדר יום פשוט לפי דחיפות, משך המשימה וכמות הזמן הפנוי. הוא עובד מקומית, ללא חשבון, ללא ענן וללא שליחת מידע החוצה.

## למי זה עוזר

* למי שמתחיל את היום עם רשימה מבולגנת
* להורים, סטודנטים, עצמאים ושכירים עם חלון זמן מוגבל
* למשתמשי Claude Code, Codex או לקוח MCP אחר שרוצים כלי שקוף ולא קופסה שחורה

## מה הכלי עושה

השרת חושף שני כלי MCP לקריאה בלבד:

### `dayplan_organize_tasks`

בונה סדר יום מלא.

| שדה | חובה | משמעות |
|---|:---:|---|
| `raw_text` | כן | משימות בטקסט חופשי, עד 8,000 תווים |
| `available_minutes` | כן | מספר הדקות הפנויות, 0 עד 1,440 |
| `start_time` | לא | שעת התחלה בפורמט `HH:MM`, ברירת מחדל `09:00` |
| `language_hint` | לא | `he`, `en` או `auto`, ברירת מחדל `auto` |

### `dayplan_parse_tasks`

מציג איך הטקסט נותח לפני השיבוץ: משך, ציון דחיפות והסימנים שהשפיעו עליו. שימושי כשרוצים להבין למה משימה קיבלה עדיפות מסוימת.

## התקנה

נדרש Node.js 20 ומעלה.

```bash
git clone https://github.com/eladshilo112/everyday-mcp-hebrew.git
cd everyday-mcp-hebrew/solutions/001-task-organizer
npm ci
npm run build

```

## חיבור ל־Claude Code

יש להחליף את `FULL_PATH` בנתיב המלא לתיקייה לאחר הבנייה.

```bash
claude mcp add --scope user everyday-dayplan -- node "FULL_PATH/dist/src/server.js"
claude mcp list
```

Claude Code יבקש אישור לפני שימוש ראשון בשרת מקומי שנוסף ברמת פרויקט. זה מנגנון תקין ולא תקלה.

## חיבור ל־Codex

```bash
codex mcp add everyday-dayplan -- node "FULL_PATH/dist/src/server.js"
codex mcp list
```

אפשר גם להגדיר ידנית ב־`~/.codex/config.toml`:

```toml
[mcp_servers.everyday_dayplan]
command = "node"
args = ["FULL_PATH/dist/src/server.js"]
required = true
default_tools_approval_mode = "auto"
```

שני הכלים מסומנים `readOnlyHint: true` ו־`destructiveHint: false`. הסימון עוזר ללקוח להציג מדיניות אישור נכונה, אבל גבול הבטיחות נאכף גם בקוד: אין גישה לקבצים, לרשת או ליומן.

## דוגמת שימוש עם Claude או Codex

```text
ארגן לי סדר יום החל מ־08:30. יש לי 90 דקות:

דחוף לשלם חשבון היום, 10 דקות
לקבוע תור לרופא, 15 דקות
להכין מסמכים למחר, 45 דקות
לקרוא מאמר, חצי שעה
```

הלקוח יקרא ל־`dayplan_organize_tasks` עם:

```json
{
  "raw_text": "דחוף לשלם חשבון היום, 10 דקות\nלקבוע תור לרופא, 15 דקות\nלהכין מסמכים למחר, 45 דקות\nלקרוא מאמר, חצי שעה",
  "available_minutes": 90,
  "start_time": "08:30",
  "language_hint": "he"
}
```

הפלט מכיל טקסט קריא וגם `structuredContent` שאפשר להעביר לכלי נוסף.

## הפעלה ללא MCP

```bash
npm run demo -- --text "דחוף לשלם היום, 10 דקות; לקרוא, חצי שעה" --minutes 45 --start 09:00
```

פלט JSON:

```bash
npm run demo -- --text "urgent call today, 10 min; read, 30 min" --minutes 35 --lang en --json
```

## איך נקבעת הדחיפות

החישוב דטרמיניסטי. אותו קלט תמיד מחזיר אותה תוצאה.

| סימן בטקסט | תוספת לציון |
|---|---:|
| ציון בסיס | 10 |
| `דחוף`, `בהקדם`, `urgent`, `asap` | 40 |
| `היום`, `today` | 25 |
| `מחר`, `tomorrow` | 10 |
| תאריך מפורש | 30 |
| שעה מפורשת או `עד` / `by` | 20 |
| `P1` | 35 |
| `P2` | 20 |
| `!!` | 20 |
| `!` | 10 |

הציון מוגבל ל־100. ציון 60 ומעלה הוא דחיפות גבוהה, 30 עד 59 בינונית, ופחות מ־30 נמוכה.

## כללי השיבוץ

1. דחיפות גבוהה לפני בינונית, ובינונית לפני נמוכה.
2. בתוך אותה רמת דחיפות, הציון הגבוה קודם.
3. במקרה של שוויון, המשימה הקצרה קודמת.
4. אם עדיין יש שוויון, נשמר הסדר המקורי בטקסט.
5. משימה שלא נכנסת בזמן שנותר עוברת לרשימת "לא שובץ", והכלי ממשיך לבדוק משימות קצרות יותר.

אם לא נכתב משך, הכלי משתמש ב־15 דקות ומציג אזהרה. משך של יותר מ־24 שעות מוגבל ל־1,440 דקות.

## איך מפרידים בין משימות

ההפרדה המומלצת היא שורה חדשה. נתמכים גם נקודה ופסיק, תבליטים ורשימות ממוספרות. פסיק רגיל אינו מפריד משימות, כדי שאפשר יהיה לכתוב תיאור טבעי עם משך באותה שורה.

## מגבלות ידועות

* זהו מנוע חוקים, לא מודל שפה. הוא אינו מבין כל ניסוח אפשרי.
* הכלי מציע סדר יום בלבד. הוא אינו מוסיף אירועים ליומן ואינו מבצע משימות.
* אין תלות בין משימות, חלונות זמן קשיחים או זמני נסיעה.
* התוצאה טובה יותר כשכל משימה מופיעה בשורה נפרדת וכוללת משך משוער.

## פרטיות ובטיחות

* אין קריאות רשת.
* אין טלמטריה.
* אין שמירת טקסט לדיסק.
* אין גישה ליומן, לדוא"ל או לחשבונות.
* אין פעולות כתיבה או מחיקה.

## English quick start

This package turns free-form Hebrew or English task lines into a deterministic local schedule. It makes no network requests and performs no external actions.

```bash
npm ci
npm run build
npm test
npm run demo -- --text "urgent call today, 10 min; read, 30 min" --minutes 35 --lang en
```
