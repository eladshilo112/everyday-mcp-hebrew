# ארכיטקטורת המאגר

המאגר בנוי כשני חלקים נפרדים: פתרונות MCP עצמאיים למשתמשים, ומערכת פיתוח מקומית שמייצרת פתרון יומי באופן מבוקר.

## פתרון MCP

כל תיקייה תחת `solutions/` היא חבילה עצמאית. השרת מתקשר ב־stdio, אינו כותב מידע ל־stdout שאינו פרוטוקול MCP, ומחזיר גם תוכן מובנה. כל פתרון חייב לפעול מקומית, ללא טלמטריה וללא פעולות הרסניות.

## מחזור הפיתוח המקומי

האוטומציה אינה נוגעת בעותק העבודה של המשתמש. בכל ריצה היא יוצרת שכפול זמני ונקי של `main` תחת `%LOCALAPPDATA%\EverydayMcpHebrew\runs`.

1. בדיקת קדם מאמתת כניסה מקומית ל־Claude Code, ל־Codex ול־GitHub.
2. Graphify מעדכן גרף AST מקומי ומחזיר שאילתה ממוקדת על הקטלוג, התבניות והמאמתים.
3. Claude מחזיר תכנית בתוך סכמת JSON סגורה.
4. מדיניות התוכן בודקת קטגוריה וביטויים אסורים לפני מימוש.
5. Graphify מחזיר תת גרף ממוקד למימוש.
6. Codex רשאי לשנות רק את התיקייה החדשה ואת `CATALOG.md`.
7. מאמתים קבועים בודקים נתיבים, תלויות, בנייה, בדיקות, MCP, סודות, תוכן וקטלוג.
8. Graphify ממפה מחדש את ההשפעה ו־Claude מבצע ביקורת סופית.
9. בדיקת הקדם מאמתת שהגנת `main` מחייבת את בדיקת `validate`, חלה גם על מנהלים ואוסרת force push ומחיקת ענף.
10. רק אז נפתחים ענף ו־Pull Request. מיזוג squash מחכה ל־CI הנדרש.

## חיסכון בטוקנים

Graphify אינו רק תרשים אדריכלי. הוא שכבת דחיסת ההקשר של המודלים. התכנון, המימוש והביקורת מקבלים שאלות שונות ותתי גרף שונים. פלט השאילתה מוגבל ל־12,000 תווים כברירת מחדל, ולכל פרומפט יש תקציב קשיח.

דוח הריצה שומר את מספר התווים שנשלחו ואת היחס לגודל הטקסט במאגר. אומדן הטוקנים מחושב לפי ארבעה תווים לטוקן ומסומן כאומדן בלבד. כאשר Claude מחזיר נתוני שימוש ממשיים, הם נשמרים בנפרד כפי שהתקבלו מהכלי.

## כשל בטוח

הריצה נעצרת ללא פרסום כאשר אימות פג, אין רשת, הגנת הענף נחלשה, כבר קיים פתרון לתאריך, ריצה אחרת פעילה, סכמת מודל אינה תקינה, הופיע נתיב לא מורשה, בדיקה נכשלה או Claude דחה את התוצאה. אם כשל מתרחש לאחר דחיפת ענף, האוטומציה סוגרת את ה־Pull Request ומנסה למחוק רק את הענף שהיא עצמה יצרה. השכפול הזמני נשמר לצורך אבחון.

## שחזור

אפשר להשבית או להסיר את משימת Windows באמצעות סקריפט ההסרה. אפשר לבטל שינוי שפורסם באמצעות `git revert`. אין force push ואין שינוי ישיר ב־`main`.
