# ארכיטקטורת המאגר

כל פתרון הוא חבילה עצמאית. שרת ה־MCP פועל מקומית ב־stdio, שומר את stdout לערוץ הפרוטוקול בלבד ומחזיר גם טקסט קריא וגם `structuredContent` מאומת בסכמה.

## שרשרת האמון

Claude מתכנן בלבד. Codex מחזיר טלאי. סקריפטים קבועים בודקים את גבולות הטלאי, את מבנה החבילה, את התלויות ואת הבדיקות. עבודת האימות רצה ללא סודות וללא הרשאת כתיבה למאגר. עבודת הפרסום מקבלת רק טלאי שכבר אומת ואינה מריצה את הקוד שנוצר.

האוטומציה מפרידה בין יצירה, אימות ופרסום בשלושה רצים נקיים. כך קוד חדש אינו מקבל גישה למפתח של מודל או לאסימון כתיבה של GitHub בזמן הבדיקות.

## תזמון

GitHub Actions מוגדר עם `timezone: Asia/Jerusalem` ו־cron של 09:00. נעילת `concurrency` ושומר תאריך מונעים שתי ריצות לאותו יום.

## גבול שינוי יומי

טלאי יומי רשאי להוסיף תיקייה אחת חדשה תחת `solutions/` ולעדכן את `CATALOG.md`. שינוי Workflows, סקריפטי אימות או פתרון קיים דורש Pull Request אנושי נפרד.
