# everyday-mcp-hebrew

פתרונות MCP קטנים, שימושיים ובדוקים לבעיות אמיתיות מחיי היום יום.

המטרה פשוטה: לפרסם בכל יום כלי קוד פתוח שאדם ממוצע יכול להפעיל עם Claude Code, Codex או כל לקוח MCP תואם, בלי למסור מידע אישי ובלי להסתכן בפעולות נסתרות.

כל פתרון כולל:

* בעיה ברורה והסבר קצר בעברית
* שרת MCP עובד בתקשורת stdio
* קוד TypeScript עם תלויות נעולות
* בדיקות יחידה ובדיקת אינטגרציה אמיתית מול MCP
* עשרה תרחישי הערכה יציבים
* הוראות הפעלה ודוגמת שימוש
* בדיקות סודות, בטיחות, פרטיות ומדיניות תוכן
* Skill אופציונלי, רק כאשר הוא מוסיף ערך אמיתי

## האוטומציה היומית

האוטומציה פועלת במחשב Windows המקומי בכל יום בשעה 09:00 לפי שעון ישראל. אין שימוש במפתח API של מודל.

1. Graphify מעדכן את מפת המאגר ומחזיר רק הקשר ממוקד ורלוונטי.
2. Claude מתכנן פתרון בתוך חוזה JSON סגור.
3. Graphify ממפה את נתיבי ההשפעה הנדרשים למימוש.
4. Codex בונה בתוך שכפול זמני ומבודד של המאגר.
5. בדיקות קבועות מקמפלות, מריצות MCP אמיתי, סורקות סודות ומוודאות גבולות תוכן.
6. Graphify מעדכן את המפה ו־Claude מבצע ביקורת סופית.
7. רק לאחר אישור מלא נפתח Pull Request, בדיקות GitHub רצות ומיזוג אוטומטי מתבצע.

Graphify משמש גם לצמצום הקשר. לכל שלב יש תקציב תווים קשיח, והרצה מקומית שומרת דוח עם גודל ההקשר ואומדן טוקנים מסומן בבירור כאומדן. כך המודלים מקבלים את תת הגרף הרלוונטי, ולא את כל המאגר.

[התקנה, הפעלה ושחזור של האוטומציה המקומית](docs/he/local-automation.md)

## גבולות התוכן

המאגר מיועד לצרכים נפוצים כמו פרודוקטיביות, קבצים, פרטיות, נגישות, תקשורת בין מכשירים וחשבונות בבעלות המשתמש, ארגון אישי ושיפור תהליכים. אפשר לפרסם גם כלים כלליים למיתוג, גרפיקה, שיווק ואסטרטגיה, כל עוד אינם משתמשים בחומר פרטי.

המאגר לא משתמש במידע אישי, בנתוני לקוחות, בחומרים עסקיים פרטיים, בנדל״ן, בסקרי שוק, ברשות המסים, בפוליטיקה או בדת. הוא אינו מפרסם כלים לחילוץ אישורים, גניבת סיסמאות, מחיקה מסוכנת או פעולה נסתרת.

## English summary

`everyday-mcp-hebrew` publishes small, tested, local-first MCP solutions for common everyday problems. Documentation is Hebrew-first. Local daily automation uses Graphify for targeted context, Claude for planning and review, Codex for implementation, and deterministic validation before a guarded pull request. No model API key is required. Start with [solution 001](solutions/001-task-organizer/README.md).
